ADMINISTRAÇÃO

Catálogo e regras de cartas

Cada entrada guarda a definição da carta. Efeitos e habilidades precisam estar implementados no motor para publicar.

Edite atributos, efeitos e habilidades no JSON. Use publicado:false durante a revisão. numeroCatalogo identifica a entrada.

Os modelos são reutilizáveis. Ajuste elemento, direção, status e valor no JSON; valide e salve a carta para aplicar.

Campos e efeitos disponíveis

Não coloque funções JavaScript no catálogo. Uma habilidade ativa pode ter alvo e uma lista de efeitos declarativos. Gatilhos passivos possuem um efeito identificado pelo nome. 


          
Exemplo de efeito

          

            Use descricao na carta, na habilidade ou na passiva para o texto
            exibido ao jogador. O comportamento é definido por efeitos; o texto
            não executa regras.
          

          
{ "descricao": "Escolha um aliado e cure 3 de vida." }

          
{ "id": "damage", "valor": 3 }

          
{ "id": "status", "status": "Cego", "duracao": 2 }

          
Exemplo de habilidade ativa

          
{ "id": "curaAliada", "nome": "Curar", "custoMana": 2, "alvo": "UnicoAliado", "efeitos": [{ "id": "heal", "valor": 3 }] }

          

            Para um comportamento novo, implemente sua regra e testes antes de
            registrá-lo como suportado. As partidas iniciadas conservam uma
            cópia das definições.
